# Brand assets

These are **placeholder** icons — a generic key glyph, not KleverKey's own
artwork. They exist so the HACS `brands` validation passes without depending on
the [home-assistant/brands][brands] repository.

Replace them with the real KleverKey artwork, or submit the `kleverkey` domain
to [home-assistant/brands][brands] and delete this directory. Listing in the
HACS default store expects the latter.

Sizes follow the brands repository conventions: `icon.png` 256×256,
`icon@2x.png` 512×512, with `logo.png` / `logo@2x.png` reusing the icon since
there is no separate wordmark.

[brands]: https://github.com/home-assistant/brands
